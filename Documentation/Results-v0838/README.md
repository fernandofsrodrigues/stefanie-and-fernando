# Original result cues, 0.8.38

Two original procedural tonal cues generated locally by Codex for this project. No external recording, melody, sample pack, paid service or AI audio model was used. `generate_results.py` records the exact synthesis, note frequencies, envelope and PCM output. These are UI signals, not recorded vehicle or combat foley; all existing recorded foley/music and their licenses remain intact.

Mono 44.1 kHz, 16-bit PCM, 1.2 seconds each. Rising major tones mark success; descending minor tones mark defeat. A dedicated result source respects the master volume, plays after simulation stops, and clears on retry/menu transitions. Listening on physical speakers remains an independent review item.
